Brainfuck interpreter

Written in Rust. Brainfuck has eight instructions, no syntax to speak of, and no way to tell what a program does except run it — which makes writing an interpreter for it a genuinely useful afternoon.

Run something

This page runs a JavaScript port of the same design, so it works without a server. Ctrl+Enter runs. The input box is a byte stream: the first , takes the first character, the next , takes the one after it, and reading past the end gives zero.

The eight instructions

> <
move the data pointer right or left
+ −
increment or decrement the byte under the pointer
. ,
output the byte, or read one in
[ ]
jump past the matching bracket if the byte is zero, or back to it if it isn't

That's the whole language. It's Turing complete, which is the joke.

The real one

The interpreter is a Rust binary, and the version running above is a port of it. I'm standing up a small hosted service that shells out to the actual compiled binary — same code you'd get from cargo build — and this page will redirect there once it's live. Until then, the port behaves the same for anything you'd reasonably type into a web page.
