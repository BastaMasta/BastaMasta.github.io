About

Sameed Ahmed — aka BastaMasta. Systems programmer from India, striving to make the world a more unified and connected place (for my own convenience, of course).

Mostly living in Rust these days — building a toy OS from scratch, a CHIP-8 emulator, and CLI tools like boxy-cli (live on crates.io). When software needs a body, I design PCBs in KiCad and build oddball hardware like an 8-bit binary keyboard.

Home server active — a Debian box hosting my own Git forge, analytics, media and automation. If it can be self-hosted, it probably already is.

Currently building ZapBurrito Studios, an indie game studio for beautiful retro-style games — and forever poking one layer deeper down the stack.
