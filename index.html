whoami

Sameed Ahmed. I write software that runs close to the metal, and when it needs a body, I design the board it runs on.

Most of my time goes into Rust — a hobby kernel that boots and then usually panics, a CHIP‑8 interpreter, and command-line tools that strangers have actually installed. Before Rust I wrote enough 8086 assembly to permanently respect what compilers do for us.

I self-host nearly everything I use. Not on principle — I just like knowing where my data sleeps.

I also run ZapBurrito Studios, which is a game studio in roughly the same way a kernel that panics is an operating system: technically, and eventually.

    RustEmulation

The rack

One Debian box in my house, doing considerably more work than it signed up for. Everything sits behind Cloudflare; everything that can be containerised is.

  • Gitea — my own Git forge, where things live before they're presentable
  • Umami — analytics that don't sell anyone out
  • Dashboard — the front door
  • Media server, automation, monitoring, backups
  • Reverse proxy, DNS, and more YAML than I'd like to admit

It has survived one power cut, two bad kernel upgrades and a cat. Uptime is a lifestyle.

BinaryKeeb 1.0

A two-key keyboard: one key for 0, one for 1. You tap eight bits and it prints the ASCII character they spell. It is a deeply impractical object and I love it.

Two keys, 0 and 1. Enter eight bits and it emits the matching ASCII character. Interactive with JavaScript enabled.
